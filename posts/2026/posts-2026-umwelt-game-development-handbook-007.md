<a id="layers"></a>
## 1｜区分事实、设计与游戏结果

| 层次 | 内容 | 不能代替的对象 |
| --- | --- | --- |
| 资料陈述 | 来源在明确对象和条件下支持的信息 | 不自动成为所有情境都成立的普遍规律 |
| 设计解释 | 作者为表达和制作作出的理解与取舍 | 不等于研究者已经给出的结论 |
| 游戏规则 | 程序实际执行的条件、状态与结果 | 不等于真实世界的完整机制 |
| 玩家理解 | 玩家根据内容和交互形成的解释 | 不一定与作者意图或事实完全一致 |

例如，资料中一个有条件的观察，可以启发某种视觉反馈；为了节奏，作品可能压缩时间或强化可见差异。只要明确这些处理，就可以进行创作，但不能再把游戏中的时长或强度当作实测值。

**资料提供依据，设计决定保留和改变什么，程序执行选定规则，试玩检查玩家怎样理解。** 写一句“仅供参考”不能代替对具体取舍的记录。

<a id="evidence"></a>
## 2｜来源核查与证据范围

研究资料的用途不同。原始研究、综述、数据库、历史档案、实地记录和创作者访谈可以互相补充，但不能只按“看起来专业”排列成同一条可信度等级。需要核对它是否确实支持正在写的那一句话。[1](#ref-1)

| 资料类型 | 可以支持的内容 | 需要注意的边界 |
| --- | --- | --- |
| 原始研究 | 特定对象、方法与条件下的结果 | 样本、研究设置与适用范围 |
| 综述或教材 | 已整理的背景与主要观点 | 出版时间、概括层次与争议处理 |
| 分类或生物多样性数据库 | 名称、记录、来源关联等 | 数据版本、鉴定与采样范围 |
| 历史档案 | 当时形成的记载与表达 | 记录者立场、保存过程与缺失 |
| 口述、访谈与参与式资料 | 当事人的经验和解释 | 同意、语境、代表范围与合作关系 |
| 图像与视频 | 可见形态、空间与动作参考 | 拍摄条件、编辑处理与使用许可 |
| 游戏开发者记录 | 某项制作过程或设计意图 | 发表时间、特定版本与作者自身视角 |

同一段文字被多个网站转载，未必是多个独立证据。资料摘要也不能替代正文中关于条件、例外和限制的部分。使用数据库时，应将页面链接或稳定标识与具体条目对应，而不只写一个网站首页。

一份最小来源记录可以包含：作者或机构、题名、日期、链接或 DOI、支持的陈述、适用对象与条件、查阅位置、访问日期、使用限制。**参考文献让读者找到来源，证据对应说明来源为什么与当前内容有关。**

<a id="translation"></a>
## 3｜从资料到交互规则

下表是一项**占位性设计演示**。其中“某种动物在特定条件下回避某种刺激”不是本篇报告的真实研究结论；实际制作时必须替换为已经核对的物种、来源与条件。

| 转化环节 | 演示内容 |
| --- | --- |
| 原始陈述 | 在某个研究或观察条件下，记录到一种回避反应 |
| 边界记录 | 适用的对象、刺激、观察方法与尚未确定的部分 |
| 设计选择 | 保留“干预改变观察条件”的关系，不追求完整生理模拟 |
| 玩家行为 | 调整观察距离或暂停干预 |
| 游戏反馈 | 通过姿态、活动或可见线索呈现条件变化 |
| 创作说明 | 反应时长和强度为作品参数，不是测量结果 |
| 验证 | 检查玩家是否误以为游戏提供了真实饲养或实验标准 |

这条流程不要求将每篇论文改编成一个任务。资料也可以决定不能表现什么、哪些内容需要保留争议，或者哪些设定应明确归为虚构。

理论可以提供观察角度，而不是替代证据。Bogost 的“程序修辞”讨论规则与过程如何参与表达。[2](#ref-2) 本系列据此采用的设计检查是：奖励、惩罚、可用操作和限制共同呈现了什么观点。这只是分析视角之一，不意味着每款游戏都必须承担明确的说服任务。

<a id="uncertainty"></a>
## 4｜简化、拟人化与不确定性

游戏需要压缩和选择，但简化应保持关键关系可解释。为了便于显示而扩大体型差异、压缩等待时间，和错误地改变资料所支持的关系，不是同一种处理。

| 处理方式 | 可以怎样交代 |
| --- | --- |
| 时间压缩 | 说明游戏时长不对应真实生长、生态或历史时间 |
| 视觉夸张 | 标明比例、颜色或动作幅度服务于辨认与风格 |
| 合并对象 | 说明使用综合形象或代理，而非完整物种／人物复原 |
| 不确定判断 | 保留来源差异及暂时采用的工作性解释 |
| 拟人化叙事 | 区分角色台词、作者表达与对真实动物认知的陈述 |
| 虚构情境 | 明确虚构部分，避免借真实术语制造已经被验证的印象 |

“未知”不一定需要被一个确定数值替代。系统可以记录信息不足、给出不同解释，或允许玩家保留判断；但这些表现仍需要清楚的界面和规则，不能以含混代替设计。

UMWELT 借用的 Umwelt 概念具有思想史背景。阅读 Uexküll 有助于理解名称与问题意识，但历史理论不能代替今天针对具体物种的研究。[3](#ref-3)[6](#ref-6) **思想来源解释创作视角，实证资料支持具体事实，两者应分别引用。**

<a id="cases"></a>
## 5｜两个作品案例

### 《Walden, a game》：把文字主题转为生活安排

创作者 Tracy Fullerton 介绍，该作品将梭罗在瓦尔登湖的生活实验、相关写作和环境观察转化为可参与的游戏体验，而不只是展示一处三维场景。[4](#ref-4)

本系列从中提取的制作判断是：改编可以发生在行动与取舍的层面。例如，作品怎样分配维持生活与观察环境的注意力，比单纯加入大量引文更接近交互设计。这里讨论的是改编方式，不把游戏视为历史生活的完整复现。

### 《Never Alone》：文化合作属于制作流程

官方资料说明，作品与阿拉斯加原住民 Iñupiat 社群成员合作，并将传统故事和文化资料纳入制作。[5](#ref-5) 这个案例的重点不是“引用了某种文化”，而是文化持有者参与了怎样的创作过程。

由此形成的项目建议是：涉及仍在生活和传承的文化时，应为合作、反馈、翻译、署名及必要的报酬安排时间与预算。公开可见不等于可以脱离语境任意改编；一位参与者的意见也不应被写成整个群体唯一的声音。

**前一个案例说明主题可以进入规则，后一个案例说明资料关系可以进入分工。** 两者都不是收集参考图之后便自动完成的工作。

<a id="umwelt"></a>
## 6｜UMWELT 的资料与表达分工

项目说明已区分资料事实、研究参考、贸易或培养名称、工作性判断、视觉参数、交互参数和虚构内容。[6](#ref-6) 配套实验室进一步规定：具体物种资料对应形态实验室中的标本，具体环境资料对应环境实验室；游戏中的资料入口与详细研究记录承担不同职责。[7](#ref-7)

| 位置 | 应承担的职责 |
| --- | --- |
| 共享来源记录 | 保存来源身份和可查入口 |
| 物种资料 | 解释来源支持哪种形态、分类或行为信息 |
| 环境资料 | 解释来源支持哪种空间、环境或过程信息 |
| 游戏内容 | 将选定信息转化为观察、操作与叙事 |
| 创作与维护记录 | 说明简化、虚构、版本变化和未解决问题 |

因此，游戏界面可以保持简洁，详细资料仍然能够追溯。简洁不意味着删去依据，而是将不同信息放到合适的位置。

新增内容可以按以下步骤组织：确定需要支持的陈述，核对来源与边界，决定设计处理，记录参数与来源的关系，完成内容接入，检查玩家理解与资料对应。修改来源后，还要判断是否只更新说明，或已影响游戏规则和历史存档。

**事实核查与游戏测试应分别记录。** 一段程序通过自动检查，不能证明物种信息正确；一条资料有可靠来源，也不能证明游戏中的交互已经正确实现。

<a id="cost"></a>
## 7｜研究工具、资料平台与成本

标注日期：**2026-10-13**。资料平台的开放获取与素材再使用许可不是同一件事。

| 工具或资源 | 开放情况 | 费用与用途 |
| --- | --- | --- |
| [Zotero](https://www.zotero.org/) | 开源软件 | 本地文献管理免费；[附件云存储扩容](https://www.zotero.org/storage)另有付费方案 |
| [Obsidian](https://obsidian.md/pricing) | 专有软件 | 本地应用免费；Sync、Publish 等可选服务付费 |
| [LibreOffice Calc](https://www.libreoffice.org/) | 开源 | 软件免费，可整理来源、参数和资源清单 |
| [draw.io](https://www.drawio.com/) | 开源核心 | 核心免费，部分集成付费，可绘制资料与设计关系 |
| [GBIF](https://www.gbif.org/) | 公共生物多样性数据基础设施 | 查询与数据获取按平台提供方式使用；具体数据许可、来源与敏感信息限制需分别查看 |
| [WoRMS](https://www.marinespecies.org/) | 海洋生物分类资料平台 | 公开查询；引用方式与数据使用条件按平台说明 |
| [Crossref](https://www.crossref.org/) | 文献标识与元数据基础设施 | 可辅助核对 DOI 和出版信息；找到记录不代表论文全文免费 |
| 出版社与图书馆 | 文献获取渠道 | 全文可能开放获取、购买或通过机构借阅；不能把订阅权限当作再分发许可 |

研究预算还包括核查时间、文献获取、翻译、专业顾问和文化合作。软件免费并不会消除这些工作；反过来，购买数据库或 AI 服务也不能自动保证结论可靠。

AI 可以辅助提出检索词、整理格式和比对文本，但生成的书目或事实仍需要回到真实来源核对。参考文献应指向实际查到的材料，不应把无法定位的 AI 输出包装成研究依据。

## 参考文献与学习资源

以下资源分为研究方法、表达理论、思想来源和项目案例，不以它们互相代替。并非都属于游戏行业教材；其中通用研究方法和思想史著作是为 UMWELT 的题材补充的阅读。网页查阅日期：**2026-10-13**。

<a id="ref-1"></a>
**[1] Booth, Wayne C. 等. _The Craft of Research_，第 5 版（2024）.** [芝加哥大学出版社](https://press.uchicago.edu/ucp/books/book/chicago/C/bo215874008.html)。书籍付费或借阅，目录与介绍免费，英文。**优先研究教材**：重点看问题范围、来源、论证和研究伦理，不要求照搬学术论文格式。
