# 基督宗教教派比较速查手册｜历史、神学、分布与社会议题

**撰写：ChatGPT · 资料检索及核对：2026-10-24**

这是一份供非宗教专业读者查阅的**宗教史与比较宗教学**手册，不是信仰劝导或对任何教派的价值排序。核心问题是：一个教会从哪里来、与哪些教会相连、在哪些地区可见、它在信什么、以及这些信仰如何（或未必如何）影响现实生活。

**先记住三个区别：**

1. **广义的「基督宗教」（Christianity）**包括天主教、东正教、东方正统教会、新教等。中文日常用语里的「基督教」有时狭义指**新教**，但在学术语境里应先说明口径。
2. **「新教」（Protestant）是教会传统的大类；「路德宗」「浸信会」是宗派家族；「福音派」（Evangelical）是可横跨多个宗派的信仰取向；「日本福音キリスト教会連合」（JECA）则是一个具体教会联合体。**四者不是同一级分类。
3. **正式教义 ≠ 教会执行方式 ≠ 信徒个人观点 ≠ 政党倾向。**本文分别记录，不用「严格／开放」一个词替代证据。

以下覆盖**主要教会家族与有代表性的分支**，不等于穷尽全球数以千计的独立教团。分类参考世界基督教协进会（WCC）的教会家族索引；统计与当代议题分别优先采用人口研究、国家统计和教会自身的一手文件。[1](#ref-01)

## 01｜历史轴：主要分歧是什么时候出现的？

| 时段 | 事件与分化 | 应怎样理解 |
|---|---|---|
| 公元1—3世纪 | 耶稣运动起源于犹太社会，随后发展为跨地区的早期教会 | 这时还没有今天的「天主教／东正教／新教」三分法。 |
| 325年、381年 | 尼西亚与君士坦丁堡大公会议，三位一体与基督论表述逐步定型 | 今日绝大多数主流教会认同尼西亚信经传统。 |
| 431年及其后 | 以弗所会议前后的基督论分歧；东方叙利亚传统的部分教会沿独立路径发展 | 后来的东方亚述教会不能简单归为「东正教分支」。[3](#ref-03) |
| **451年及其后** | 迦克墩会议的基督论争议，引出今日所谓**东方正统教会**的独立传统 | 科普特、亚美尼亚、埃塞俄比亚等教会属这一家族，**不等于**希腊、俄罗斯所属的东正教。[2](#ref-02) |
| **约1054年前后** | 罗马与君士坦丁堡之间的东西方教会分裂达到标志性节点 | 分裂持续了数世纪，1054年并非一天之内突然出现两套教会。[4](#ref-04) |
| 1517年起 | 马丁·路德及其他改革者推动西方宗教改革 | 逐渐形成路德宗、改革宗、圣公会等新教传统；新教并非单一组织。[1](#ref-01)[4](#ref-04)[5](#ref-05) |
| 16世纪20—40年代 | 瑞士改革运动、再洗礼运动、英格兰宗教改革 | 改革宗、再洗礼派、圣公会的起点不同，不是从路德宗依次「派生」。 |
| 17世纪 | 浸信会、公理宗、贵格会等壮大 | 重点分歧包括谁能受洗、谁有权治理地方教会。 |
| 18世纪 | 卫斯理复兴与卫理宗发展 | 特别强调成圣、个人生活与社会关怀。 |
| 19世纪 | 圣洁运动、基督复临运动、救世军、许多宣教教团发展 | 一些是宗派，一些是跨宗派的运动或组织。 |
| **20世纪初** | 现代五旬节运动迅速扩展，1906年阿苏萨街复兴是重要标志 | 特别强调圣灵恩赐，但并非所有福音派都属于五旬节派。 |
| 20世纪中后期至今 | 灵恩运动、独立教会、跨宗派联合与教会合一运动发展 | 一个地方教会可能同时具有某宗派背景和福音派／灵恩派取向。 |
| **1992年** | 日本福音キリスト教会連合（JECA）成立 | 这是日本具体联合体的成立时间，**不是福音派或新教的诞生时间**。[25](#ref-25) |

**历史图的读法：**早期基督教会逐渐出现多条发展路线；今日的天主教、东正教和东方正统教会都主张与古代教会的连续性。把新教说成「从16世纪的西方教会改革中形成」较准确；把东正教说成「天主教在1054年创立的另一派」则失真。[1](#ref-01)[2](#ref-02)[4](#ref-04)

## 02｜谱系轴：大的分类之下有哪些教派？

按「历史教会家族 → 宗派／自治教会 → 具体组织」三层阅读：

| 教会家族 | 代表性内部传统／教会 | 最便于辨认的特征 | 历史核心地区与当代分布 |
|---|---|---|---|
| **天主教** Catholic Church | 拉丁教会；乌克兰希腊礼、马龙派等**东方天主教会**；内部另有耶稣会、方济各会等修会 | 各自礼仪可不同，但与罗马教宗共融；修会不是独立宗派 | 拉丁美洲、欧洲、菲律宾、北美、非洲多国 |
| **东正教** Eastern Orthodox | 君士坦丁堡、希腊、俄罗斯、塞尔维亚、罗马尼亚、格鲁吉亚、日本正教会等 | 拥有自治或自主治理的教会体系，传统礼仪与圣像重要；不承认罗马教宗的普世管辖权 | 东南欧、东欧、俄罗斯及全球移民社群 |
| **东方正统教会** Oriental Orthodox | 科普特正教会、亚美尼亚使徒教会、埃塞俄比亚与厄立特里亚正统教会、叙利亚正统教会、印度马兰卡拉正统叙利亚教会 | 与451年迦克墩会议的基督论争议有关；不等于拜占庭传统的东正教 | 埃及、埃塞俄比亚、厄立特里亚、亚美尼亚、叙利亚、印度及移民社群[2](#ref-02) |
| **东方亚述教会** Church of the East | 东方亚述教会及相关东方叙利亚传统 | 形成于波斯—两河流域传统；历史上曾沿丝路传播，在中国史中与景教有关 | 伊拉克、伊朗、印度及离散社群[3](#ref-03) |
| **新教** Protestant | 路德宗、改革宗／长老会、圣公会、浸信会、卫理宗、圣洁派、五旬节派、复临安息日会、独立教会等 | 通常强调圣经在信仰判断中的根本地位；圣礼、治理与礼拜方式差异显著 | 欧洲、北美、撒哈拉以南非洲、拉美、韩国及其他亚洲地区[1](#ref-01) |
| **其他相关历史教会与运动** | 旧天主教、摩拉维亚弟兄会、贵格会、救世军、非洲自立教会等 | 与上述家族有历史联系，却不能总按单一上下级树形图安放 | 欧洲、非洲、美洲及其他地区[1](#ref-01) |

**容易混淆的名称：**「东方正统教会」（Oriental Orthodox）和「东正教」（Eastern Orthodox）是两个不同教会家族；「东方天主教会」虽然也有东方礼仪，却仍属于与罗马教宗共融的天主教。[1](#ref-01)[2](#ref-02)

### 新教内部：使用同一标准横向对照

以下的「分布」是**代表性历史及当代地区**，不是教徒数量排行。

| 宗派／传统（日语线索） | 形成背景 | 神学或圣礼辨识点 | 教会治理；代表地区 |
|---|---|---|---|
| **路德宗** Lutheran（ルーテル） | 16世纪德国宗教改革 | 因信称义；常保留婴儿洗礼和较固定的礼仪，重视圣餐中基督真实临在 | 传统教会组织；德国、北欧、美国、非洲 |
| **改革宗／归正宗** Reformed（改革派） | 16世纪瑞士等地宗教改革 | 上帝主权、恩典与圣经讲解；常接受婴儿洗礼 | 多采用长老治理；瑞士、荷兰、苏格兰、韩国及全球 |
| **长老宗** Presbyterian（長老派） | 改革宗的一个重要治理传统 | 与改革宗神学密切相关；不是完全另起炉灶的神学家族 | 牧师与长老共同治理；苏格兰、美国、韩国等 |
| **圣公会／安立甘宗** Anglican（聖公会） | 16世纪英格兰宗教改革 | 公祷书与礼仪传统突出；内部从偏天主教式到福音派式差异很大 | 主教制；英国、美国、尼日利亚、乌干达、澳洲、日本等 |
| **公理宗／会众派** Congregational（会衆派・組合派） | 16—17世纪英格兰清教徒与独立教会传统 | 强调地方会众及其盟约生活 | 地方教会自治；英美等 |
| **再洗礼派／门诺会** Anabaptist/Mennonite（メノナイト） | 16世纪激进宗教改革 | 主张自觉信仰后的信徒洗礼；许多群体重视和平主义、门徒生活 | 地方与团契网络；欧洲、北美、非洲、拉美 |
| **浸信会** Baptist（バプテスト） | 17世纪英国及其后发展 | 强调信徒洗礼、通常浸水；圣餐解释多为纪念取向 | 地方教会自治；美国、非洲、亚洲与拉美 |
| **卫理宗／循道宗** Methodist（メソジスト） | 18世纪英国卫斯理运动 | 强调恩典、成圣、个人及社会实践；通常接受婴儿洗礼 | 联会制等；英美、非洲、韩国 |
| **圣洁派** Holiness（ホーリネス） | 19世纪卫斯理—圣洁运动 | 强调信徒生活中的圣洁与成圣 | 组织不一；美国、日本、韩国等 |
| **五旬节派** Pentecostal（ペンテコステ） | 20世纪初复兴运动 | 强调圣灵洗、方言、医治等恩赐；各派解释不同 | 宗派与独立教会并存；非洲、拉美、美国、亚洲 |
| **复临安息日会** Seventh-day Adventist（アドベンチスト） | 19世纪美国复临运动 | 重视再来、星期六安息日及健康生活 | 全球性教团；美洲、非洲、亚洲 |
| **贵格会** Quaker／Friends（クエーカー） | 17世纪英国 | 强调良心、属灵引导；部分传统以静默聚会及和平见证著称 | 团契组织多样；英国、美国、非洲 |
| **摩拉维亚弟兄会** Moravian（モラヴィア兄弟団） | 捷克宗教改革遗产，18世纪复兴 | 虔敬、诗歌、宣教传统 | 欧洲、美洲、非洲 |
| **救世军** Salvation Army（救世軍） | 19世纪卫斯理圣洁传统 | 传教和社会救助突出；不举行传统洗礼、圣餐仪式 | 国际性组织；英美、日本及多国 |
| **普利茅斯弟兄会** Brethren（ブレザレン） | 19世纪英国弟兄运动 | 强调信徒参与、圣经学习及地方聚会 | 地方独立网络；欧美、亚洲等 |
| **联合／无宗派教会** United / Nondenominational（合同・無教派） | 多宗派合并，或选择不隶属既有宗派 | **不是统一神学立场**：可偏福音派、灵恩派或较开放 | 世界各地；须逐个核对具体教会 |

宗派表中的「通常」表示常见教义或组织特征，而非所有使用该名字的教会必然相同。家族索引及各教会简介可从WCC逐项查找。[1](#ref-01)

### 五种经常被误画成「新教子宗派」的标签

| 名称 | 实际是哪一层？ | 与其他宗派的关系 |
|---|---|---|
| **福音派** Evangelical（福音派） | 跨宗派信仰运动 | 重视圣经权威、个人归信、耶稣救赎与传福音；浸信会、圣公会、长老会、独立教会中均可能存在 |
| **基要主义** Fundamentalism（根本主義） | 神学—文化运动 | 强调保护基本教义、反对某些现代主义解释；不能简单把所有福音派等同于基要主义 |
| **灵恩派** Charismatic（カリスマ派） | 跨教会运动 | 重视圣灵恩赐；可出现于五旬节派、新教其他宗派，甚至天主教内部 |
| **主流新教** Mainline Protestant | 尤其用于美国社会学／人口调查的分类 | 不是全球统一的神学宗派，也不代表成员都持相同政治观点 |
| **无宗派** Nondenominational（無教派） | 组织归属方式 | 没有传统宗派标签，不代表没有固定教义或一定宽松 |

## 03｜神学轴：究竟什么使这些传统真正不同？

比起「是否过圣诞节」——多数主要基督教会都会庆祝，只是部分东正教会采用不同历法——以下问题更有区分力。

| 比较问题 | 天主教 | 东正教／东方正统教会 | 新教（各宗派之间仍须细分） |
|---|---|---|---|
| **权威从何而来？** | 圣经、圣传与教会训导，教宗权威重要 | 圣经置于教会圣传、礼仪与大公会议传统之内；不接受罗马教宗的普世管辖权 | 通常以圣经为最高规范，如何理解信经、传统及教会解释权仍有差异 |
| **何为正确的基督论？** | 接受迦克墩及后续公会议教义 | 东正教接受迦克墩；**东方正统教会**沿用非迦克墩传统的基督论表述 | 主流三位一体新教通常接受尼西亚—迦克墩传统；另有例外 |
| **如何理解得救？** | 恩典、信德、圣礼与合作的综合教导 | 强调在恩典中的参与、成圣与神化（theosis） | 路德宗／改革宗突出因信称义；不同新教传统对预定、成圣与自由意志理解不同 |
| **洗礼给谁？** | 婴儿和成人均可受洗 | 通常接受婴儿洗礼 | 路德、改革、圣公、卫理多接受婴儿洗礼；浸信会、门诺会则强调信徒自觉受洗 |
| **圣餐意味着什么？** | 饼酒实体变化（transubstantiation）等明确教义 | 强调圣体奥迹与基督真实临在，哲学定义方式不完全相同 | 路德宗强调真实临在；改革宗强调属灵临在；部分浸信会侧重纪念 |
| **谁管理教会？** | 罗马教宗—主教—司铎系统 | 各自治教会由其主教会议等治理 | 主教制、长老制、会众制、联合制并存 |
| **圣母、圣人、圣像？** | 尊崇圣母与诸圣，可请求代祷；区分敬礼与敬拜 | 强调圣像、圣母与诸圣；具体传统礼仪有别 | 多数不向圣母或圣人请求代祷；圣公会、路德宗等保留程度不同 |
| **圣灵恩赐？** | 接受圣灵工作，也存在天主教灵恩运动 | 有丰富灵修传统，不以现代五旬节实践作统一标识 | 五旬节／灵恩派特别重视方言、医治等；其他教会可持不同立场 |
| **女性可以担任何种神职？** | 不允许女性领受司铎圣秩 | 传统上不允许女性担任司祭 | 部分圣公、路德、卫理、五旬节教团按立女性；部分浸信、改革宗及福音派教会不允许女性担任牧师 |

**两条说明：**「天主教不读圣经」「东正教不信恩典」「所有新教都否定圣礼」都是错误概括；对基督论也不能把东方正统教会简单称为「只相信耶稣有神性」。不同教会争论的通常是权威结构、用语、圣礼性质与教会治理，而非是否承认耶稣这一人物。[1](#ref-01)[2](#ref-02)

## 04｜地理轴：主要分布与人口比例

### 4.1 先看全球基督徒住在哪里

Pew Research Center于**2025年发布**的新估算，基准是**2020年**。彼时全球约有**22.7亿基督徒**，占全球人口**28.8%**。下表故意保留两个不同的分母：一个是当地人口中有多少人认同基督宗教，另一个是全球基督徒有多少居住在那里。[6](#ref-06)[7](#ref-07)

| 地区（2020年） | 基督徒约数 | **该地区居民中**基督徒占比 | **全球基督徒中**居此地占比 |
|---|---:|---:|---:|
| 撒哈拉以南非洲 | 6.97亿 | 62.0% | 30.7% |
| 拉丁美洲与加勒比 | 5.47亿 | 84.6% | 24.1% |
| 欧洲 | 5.05亿 | 67.1% | 22.3% |
| 亚太 | 2.69亿 | 5.9% | 11.8% |
| 北美 | 2.38亿 | 62.9% | 10.5% |
| 中东与北非 | 约1,300万 | 2.9% | 0.6% |
| **世界合计** | **约22.7亿** | **28.8%（全球人口）** | **约100%** |

数据经四舍五入。**全球最多基督徒生活的地区已经是撒哈拉以南非洲，而不是欧洲。**不能因为某派起源于德国或英国，就以为今日信徒主要仍在欧洲。[6](#ref-06)

### 4.2 教派在全球的比例：为什么不能把不同年份混成一张「2026排行榜」

Pew于2011年发表、基于**2010年前后资料**的全球基督教传统分类估算为：天主教约50%、广义新教约37%、广义正教约12%、其他约1%。其中「广义正教」包含东正教与东方正统教会；「其他」的统计口径也包括一些不属于尼西亚信经传统的团体。这是**历史口径的估算，不是2026年的即时比例**。Pew的2025年全球报告则只把所有基督徒作为一个总体统计，不能拿它更新前述宗派分布。[8](#ref-08)[6](#ref-06)

### 4.3 几个国家与地区的可核对例子

| 国家／地区 | 调查年份及统计对象 | 已公布的比例或结构 | 看得出什么 |
|---|---|---|---|
| **美国** | 2023—2024年，成年人抽样调查 | 62%认同基督宗教；其中按**全体成年人**算，40%新教、19%天主教、约3%其他基督徒 | 新教内部又可按福音派、主流派、历史黑人新教传统等调查分类。[9](#ref-09) |
| **巴西** | 2022年人口普查，**10岁及以上**居民 | 56.7%天主教；26.9%福音派／新教（巴西普查用语） | 仍以天主教为最大群体，福音派人口明显增长。[10](#ref-10) |
| **墨西哥** | 2020年人口普查，全体人口 | 约78%自认天主教 | 天主教在人口结构中仍占主要地位。[11](#ref-11) |
| **菲律宾** | 2020年人口普查，家庭人口 | 78.8%报告罗马天主教 | 亚洲天主教分布的重要代表。[12](#ref-12) |
| **韩国** | Pew 2023年东亚成年人调查（2024年发表） | **约三分之一**成年人自认基督徒；其中约一半基督徒自认「重生／福音派」 | 基督徒、福音派、官方宗派会员不能画等号。[13](#ref-13) |
| **日本** | 文化厅每年公布宗教团体行政统计；Pew另有成年人身份调查 | 基督宗教是少数信仰传统，但这里**不把团体申报信徒数直接换算为全国比例** | 组织登记、所属人数与自我认同的分母不同。[14](#ref-14)[13](#ref-13) |

**统计纪律：**美国、韩国是成年人问卷；巴西是10岁及以上居民；菲律宾是家庭人口；墨西哥是全人口。不可直接将这些百分比排名，也不可用「宗教法人数量」代表信徒数量。各国的「Evangelical」还可能分别指信仰运动、某类新教或国家普查中的归档类别。[6](#ref-06)[9](#ref-09)[10](#ref-10)

## 05｜现实生活轴：伦理、家庭、政治经济议题怎么比较？

做这一轴时，不采用「整个新教支持堕胎」「整个福音派支持某党」这类不可检验的句子。**对每条立场先问：谁说的、何年文件、约束哪些教会、是否只是信徒调查？**

下面的每一行是**具体教会或教团的可查文本**，不是对同名世界宗派的一揽子判决。尤其美国教团文件不能自动代表日本或非洲同宗派教会。

### 5.1 生育、婚姻、性伦理与神职

| 教会／文件主体 | 堕胎与避孕 | 离婚与再婚 | 同性婚姻／女性神职 | 证据边界 |
|---|---|---|---|---|
| **罗马天主教** | 正式教义反对直接堕胎；反对夫妻使用人为阻断生育的避孕行为，允许按自然周期调节生育 | 有效的、已圆房圣事婚姻原则上不可解除；必要时可分居或民事离婚。宣告婚姻无效**不是**批准有效婚姻离婚 | 婚姻圣事按男女结合理解；不允许女性领受司铎圣秩 | 《天主教教理》相关段落，属于较统一的正式训导。[15](#ref-15)[16](#ref-16)[17](#ref-17) |
| **美国正教会 OCA（东正教例子）** | 正式声明反对堕胎；特殊医疗状况需依具体声明理解 | 不鼓励离婚，但可以经教会酌情处理，允许第二、甚至第三次婚姻 | 维持传统男女婚姻及男性司祭制度 | 这里仅以**OCA**为例，不替其他所有正教会发布统一规定。[18](#ref-18)[19](#ref-19) |
| **美南浸信会 SBC（浸信会例子）** | 《信仰与信息》强调胎儿生命保护 | 强调男女终身婚约；具体个案处理依地方教会 | 婚姻按一男一女理解；牧师职分限于符合其教义规定的男性 | SBC的信仰声明；**不能推广为所有浸信会**。[20](#ref-20) |
| **美国福音路德教会 ELCA（路德宗例子）** | 堕胎声明强调伦理辨识与情境判断，不能简单标成「全面赞成」 | 接纳不同家庭处境；具体礼仪与教会实践另查 | 按立女性；允许已公开同性伴侣关系的神职人员服事 | 仅指**ELCA**；保守路德宗会有不同规定。[21](#ref-21)[26](#ref-26) |
| **联合卫理公会 UMC（卫理宗例子）** | 2020／2024《社会原则》承认复杂怀孕处境，强调对妇女的支持和对生命的尊重 | 重视稳定婚姻、家庭关怀 | 其更新后的文本承认两名成年人的婚姻，包含同性伴侣；按立女性 | 指**UMC现行规则**，不代表所有卫理宗及已与UMC分离的教会。[22](#ref-22) |
| **美国神召会 AG（五旬节派例子）** | 正式文件通常反对堕胎，亦讨论高风险妊娠等难题 | 2024年立场文件承认通奸、遗弃、家暴等特定情况下离婚与再婚 | 维持传统男女婚姻观，但**允许女性担任按立教牧** | 「保守性伦理」和「女性能否当牧师」不是同一个维度。[24](#ref-24) |
| **日本 JECA（福音派联合体）** | 公开信仰告白未提供足以推断所有加盟教会处理堕胎、避孕的统一细则 | 同理：不能据福音派名称直接推断每一教会的离婚再婚标准 | 需查询具体教会与连合规定，不作没有依据的统一判定 | 已核对其历史沿革及信仰告白说明；此处标明**证据不足**，不是说「没有态度」。[25](#ref-25) |

**重要区分：**信徒可能并不遵守所在教会全部伦理规范；某国的离婚法、堕胎法或婚姻法，也不自动等于宗教规定。对于家暴场景，不能把重视婚姻解释为要求受害者留在危险关系中；例如美国神召会的官方文件明确将家暴列为可构成婚约破裂的情况。[24](#ref-24)

### 5.2 政治、经济、劳动、科学与社会关怀

不建议再加一列「左／右」，因为教派不是政党、不同国家左右议题划线不同，正式教导也不必与信徒投票一致。更可核查的是**具体公共议题与正式声明**。

| 比较轴 | 可核查的教会立场或现实差异 | 不能直接推出什么 |
|---|---|---|
| **贫困、劳动和经济公平** | UMC现行《经济共同体》支持体面工资、集体谈判和工会权利，反对把富裕简单视为上帝喜爱的证明。[23](#ref-23) | 不能由此判定所有卫理宗信徒支持某一种税制、政党或经济学派。 |
| **慈善和社会服务** | 救世军、天主教慈善网络、各类新教医院和教育机构均参与社会服务，具体组织和资金来源不同。[1](#ref-01) | 从事慈善不等于其全部社会立场相同。 |
| **环境与气候** | UMC《自然世界》社会原则讨论全球变暖、能源与环境不公。[23](#ref-23) | 不能据此推断所有基督徒对每项环境政策有同一主张。 |
| **财富与繁荣神学** | 某些独立教会、灵恩或五旬节网络传播「繁荣福音」；也有教会明确批评将财富等同于神的赞许。[23](#ref-23) | **繁荣神学不是整个五旬节派或整个福音派的统一教义。** |
| **战争、和平与国家** | 再洗礼传统中的部分门诺会、贵格会特别强调和平主义；其他教会有正义战争或国家责任的伦理讨论。[1](#ref-01) | 无法推出所有该教派成员均拒绝服兵役，或都支持同一政府。 |
| **科学与进化论** | 对创世记、进化、生物伦理的解释会随教团与神学立场变化；福音派内部同样存在分歧 | 「相信圣经」不能自动转换成「反科学」，也不能把神学描述当作自然科学验证。 |
| **性别与公共生活** | 同一新教家族内，可能一派接受女性牧师、另一派拒绝；在同性婚姻等议题上亦可发生组织分裂。[20](#ref-20)[22](#ref-22)[24](#ref-24) | 无法据「新教」「圣公会」四字判断地方教会的全部伦理与政治态度。 |

在研究具体教会的当代社会立场时，最有效的做法不是猜测它「保守还是自由」，而是依次核对：**信仰告白 → 教团章程及社会声明 → 地方教会公告 → 具日期与样本口径的信徒调查**。没有文献时，保留「未核实」比填入一个看似整齐的判断更准确。

## 06｜一个日本实例：「福音キリスト」应该放在哪里？

以**日本福音キリスト教会連合**（Japan Evangelical Church Association，**JECA**）为例：

| 标准字段 | 核对结果 |
|---|---|
| 基督宗教家族 | **新教 Protestant** |
| 跨宗派神学取向 | **福音派 Evangelical** |
| 具体组织层级 | 日本各地方教会组成的**教会联合体**，不是全球所有福音派的总部 |
| 成立 | 1992年4月29日；由数个此前逐步合作的教会团体合并形成 |
| 对圣经的态度 | 官方明确以新旧约**66卷圣经**为信仰与生活的规范，信仰告白称其为神所默示、没有错误的话语 |
| 教会组织 | 强调地方教会自主、自立，同时重视区域与跨教会合作 |
| 历史背景 | 受跨宗派宣教团体、德国敬虔主义等因素影响 |
| 不能直接确定 | **所有**加盟教会对离婚再婚、避孕、堕胎、同性婚姻的具体执行规则 |

以上对应其官方「歴史と沿革」文档，而不是根据「福音」两个字做推测。[25](#ref-25)

看到日本教会名称时，可以这样判断：

1. 「カトリック」通常指天主教；「ハリストス正教会」为正教传统；「聖公会」为圣公会传统。
2. 「ルーテル」偏路德宗；「バプテスト」为浸信会；「ホーリネス」为圣洁派；「ペンテコステ」为五旬节派。
3. 「福音キリスト」「福音教会」只是名字的组成部分；**先查正式法人名称和所属团体**。比如「福音ルーテル」的「福音」也是历史教会名称的一部分，不能仅据此判定为当代狭义福音派。
4. 「日本基督教団（UCCJ）」是历史上由多个新教宗派合并而成的联合教团，也不能被理解为「日本所有基督徒的单一总会」。

## 07｜一分钟识别法与研究边界

判断一个陌生教会，可以按此顺序提问：

1. **它属于哪一个历史家族？**天主教、东正教、东方正统教会、新教，还是其他基督宗教相关群体？
2. **它承认哪套教会权威？**教宗、主教会议、长老、地方会众，还是独立牧师团队？
3. **它如何理解洗礼与圣餐？**婴儿洗礼还是信徒洗礼？圣餐真实临在还是主要纪念？
4. **它属于什么具体教团？**不要把某个国家教团与全球同宗派全部教会混为一谈。
5. **它的社会伦理主张来自哪里？**是否有正式文件，文件何年通过，是否同样约束所有地方教会？
6. **它的信徒主要在哪？**报告说的是全球教徒占比、当地人口占比、成年人自认身份，还是组织申报人数？

**关于耶和华见证人、耶稣基督后期圣徒教会（俗称摩门教）等：**它们各有自己的基督教身份理解；宗教人口研究也可能将之归入广义基督教统计。然而它们的三位一体、经典或神观与尼西亚信经传统不同，通常不放在前述天主教—正教—主流三位一体新教的教义谱系内。**人口分类与教义分类可能不同**，必须声明标准。[8](#ref-08)

**核对限制：**本文以2026-10-24为资料核对时点。涉及人口时分别写明数据**测量年份**与**发表年份**；涉及教义时优先看公开信仰告白与官方声明；涉及「主流／保守／福音派」时说明它是分类工具，不是道德评价。若一项社会议题没有全教团统一文件，保留差异而不进行空白填充。
